# Growify Website Redesign & Digital Strategy Assignment

## Project Overview

This project was developed as part of a practical assignment for Growify Digital LLP. The objective was to create a modern, responsive website experience and supporting digital strategy documentation to improve the presentation of the company's services, products, and digital capabilities.

The project combines front-end web development, website structure, user experience, and SEO strategy into one assignment submission.

## Objectives

- Design a clean, professional, and responsive website.
- Organize company information, services, products, and case studies into clear sections.
- Create an intuitive navigation experience across multiple pages.
- Present the company's digital capabilities through a consistent visual identity.
- Prepare supporting SEO and website strategy documentation.
- Build a lightweight website using HTML, CSS, and JavaScript.

## Key Features

- **Multi-page Website:** Separate pages for Home, Services, Case Studies, Products & Technology, About, and Contact.
- **Responsive Layout:** CSS-based layouts designed to adapt to different screen sizes.
- **Interactive Navigation:** JavaScript functionality for mobile navigation.
- **Modern UI:** Consistent styling, typography, spacing, and calls to action.
- **Product Presentation:** Dedicated sections for Growify's product ecosystem.
- **SEO & Strategy Documentation:** Supporting recommendations for website structure, content, and search visibility.
- **Lightweight Implementation:** Built without a front-end framework or complex build process.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, open the folder in Visual Studio Code and use the Live Server extension.

No additional package installation or build command is required.

## Current Scope & Limitations

- The website is a practical assignment prototype and is not presented as an officially deployed company website.
- The contact form is a front-end prototype and does not provide a complete backend or CRM integration.
- Case-study content and business claims should be verified and approved before publication.
- Further accessibility, performance, cross-browser, and SEO testing is recommended before production use.
