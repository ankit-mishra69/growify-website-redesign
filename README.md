# Growify website redesign — practical assignment prototype

A responsive, multi-page static website concept created for the Growify Digital LLP AI Generalist practical assignment. It uses plain HTML, CSS and JavaScript so it can be opened and previewed without installing Node.js, npm, Cursor or any other software.

## Open locally
1. Extract the ZIP.
2. Open the `growify_submission` folder.
3. Double-click `index.html` to open the homepage in a browser.
4. Use the navigation to visit Services, Case Studies, Products & Technology, About and Contact.
5. To edit, open the folder in VS Code.

No build step is required. Google Fonts are optional; if offline, the site falls back to system fonts.

## Included
- `index.html` — homepage
- `services.html` — service overview
- `case-studies.html` — two designed case-study concepts and six future concepts
- `products.html` — Lookify, Rossify, Craftify and integration ecosystem
- `about.html` — company positioning and industries
- `contact.html` — enquiry form prototype (opens an email draft; no server submission)
- `assets/styles.css` — responsive design system and mobile layouts
- `assets/app.js` — mobile navigation, current year and mailto form behaviour
- `STRATEGY_AND_SEO.md` — audit assumptions, positioning, sitemap, SEO map, workflow and launch checklist
- `SUBMISSION_CHECKLIST.md` — final review checklist

## Important limitations / honesty
- This is a redesign concept, not a production replacement for the live Growify website.
- No live deployment URL is included because deployment requires the candidate to sign in to a hosting service and publish the project.
- No real client outcomes, testimonials or unsupported partner claims are invented. Case studies are explicitly illustrative and require approved evidence.
- Product details for Rossify and Craftify are marked as pending confirmation. Confirm the official Lookify URL and all integration/partner relationships before publication.
- The enquiry form uses a `mailto:` draft and is not connected to a CRM or backend.
- Competitor comparisons and detailed performance claims should be verified through a separate live research pass before final submission.

## Before submission
1. Review all pages and test the links.
2. Verify product URLs, partner names, brand permissions and any case-study evidence with Growify.
3. If you have time, publish to a hosting platform such as GitHub Pages or Netlify and include the real preview URL. Do not claim a live URL until it works.
4. Record a 2–3 minute walkthrough of the homepage and inner pages.
5. Submit the live preview URL, source files, walkthrough video and strategy document as requested in the brief.
